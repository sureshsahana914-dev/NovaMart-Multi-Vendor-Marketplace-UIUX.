# NovaMart User Flows

## Customer purchase
Home → Search → Search Results → Product Details → Cart → Checkout → Payment → Order Confirmation → Order Tracking.

Key states: no search results, loading, out of stock, invalid coupon, payment failure, empty cart, order success.

## Vendor onboarding
Become a Seller → Create Account → Business Details → KYC → Bank Details → Store Setup → Add Product → Dashboard.

Key states: field validation, upload progress, upload success/error, application pending, product approval requested.

## Admin moderation
Admin Dashboard → Vendor Management → Vendor Approval → Product Moderation → User Management → Analytics.

Key states: pending/approved/rejected/suspended, confirmation dialog for rejection, empty filtered results, permission or loading error.
