## Typography
Suggested starting point: Inter or another accessible sans-serif.
- Page title: 28–32 px desktop
- Section heading: 20–24 px
- Body: 14–16 px
- Helper text: 12–14 px

## Spacing
4, 8, 12, 16, 24, 32, 40, 48, 64 px.

## Suggested frames
- Desktop: 1440 × 1024
- Mobile: 390 × 844
- Desktop grid: 12 columns, 72–80 px margins, 24 px gutters
- Mobile margins: 16–18 px

## Components to build
Header, mobile bottom navigation, buttons, form fields, product cards, category cards, status badges, filter panel, mobile filter sheet, toast, inline error, empty state, skeleton loader, order timeline, vendor/admin tables.

## Accessibility
Record actual checks after reviewing the final design: contrast, readable text, focus states, touch target sizes, keyboard navigation, and status labels that do not depend on color alone.
